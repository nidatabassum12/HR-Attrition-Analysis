## Overview
This project analyzes employee attrition using SQL, Excel, and Power BI to identify workforce trends and key factors influencing employee turnover.

## Tools Used
- SQL
- Power BI
- Microsoft Excel

## Features
- Employee Attrition Rate
- Department-wise Analysis
- Job Role Analysis
- Gender-wise Attrition
- Age Group Analysis
- Interactive Filters (Slicers)
- KPI Dashboard

## Dataset
IBM HR Analytics Employee Attrition Dataset

## Key Insights

- The overall employee attrition rate is **16%**.
- Research & Development has the highest employee attrition.
- Sales Representatives have one of the highest attrition counts among job roles.
- Male employees account for approximately **63%** of attrition.
- Single employees show higher attrition compared to married and divorced employees.
- Interactive filters enable analysis by department and gender.
 ## How to Use

1. Clone or download this repository.
2. Open `HR-Employee-Attrition.pbix` in Microsoft Power BI Desktop.
3. Refresh the data if necessary.
4. Explore the dashboard using the interactive filters.
